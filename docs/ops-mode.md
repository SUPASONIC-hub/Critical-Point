# 운영 규칙

매일 배포합니다. 18:50까지 검사가 초록인 PR은 그날 병합하고 배포합니다. 요일도, 분기 고정일도 없습니다.
결정: 2026-11-25, 사용자. 「12-01부터 배포는 화·금만」 운영 모드(11-12 방향 질의 Q4·Q5)와
「랭킹 비움과 규칙 숫자 변경은 분기 첫 월요일만, 14일 전 예고」 규칙을 이날 없앴습니다.

## 1. 준비되면 병합

- 화면·규칙·글·서버(마이그레이션)가 바뀌는 PR도 문서·테스트·도구 PR도 같습니다. 검사가 초록이고 main 최신이면 그날 병합합니다.
- 마이그레이션은 병합 전 번호 질문 한 번(묶음으로 모아 한 번).
- 랭킹 비움과 규칙 숫자 변경도 준비되면 병합합니다. 정해 둔 날이나 14일 예고 기간을 기다리지 않습니다.

## 2. 이야기와 노트는 바로 공개

- Season 예고제는 없습니다. 준비된 이야기(번외)는 예고 없이 바로 공개합니다.
- 노트에는 연재 날짜가 없습니다. 써 둔 노트는 바로 공개합니다.

## 3. 운영 데이터 판정은 미룸

- 결정 T 같은 운영 데이터 판정은 사용자가 날짜를 정할 때까지 미룹니다(기한 없음).

## 4. 측정

- 레이아웃 측정·스윕·probe는 병합 뒤 한 번, 20 job 이하, after만. 병합이 배포를 기다리면 probe를 취소합니다.

## 5. 매일 자동으로 도는 것

- `Funnel`(funnel·오류·의견·운영 달력, 예산 80% 알람), `Board Reports`(신고), `Test Week`, `Verify Ranking`(23:55 검사·명예 확정),
  `Migration Drift`, 매달 1일 `Workflow Keepalive`.
- Supabase pg_cron 매일 정리(180일 지난 기록·온라인 저장).
- 주간 규칙 달력(`src/gauntlet/weeklyCalendar.js`)은 월요일 0시에 저절로 넘어갑니다.
- 사람이 매일 하는 일: 알람 메일 확인 1분.

## 6. 주간 규칙 달력 채우기

```
node scripts/ops-calendar.mjs            # 오늘 한 줄: 주간 규칙 달력이 몇 주 남았는지
node scripts/ops-calendar.mjs --summary  # Funnel 요약의 「운영 달력」 절
```

- `Funnel`(매일 22:10 KST) 요약 끝의 「운영 달력」 절이 남은 주를 적고, 6주 밑이면 경고가 뜹니다.
- 남은 예약이 6주 밑이면 12주를 더 붙입니다(`weeklyCalendar.js` + 서버 `weekly_rules` 마이그레이션, 번호 질문 한 번).
