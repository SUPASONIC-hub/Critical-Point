# 2026-09-09

## 콜드 오픈 (2026-09-09, 첫 클릭이 첫 장면을 연다)

"개선이 정체되어 있다"는 피드백에서 출발한 사이클입니다. 원인은 아이디어 고갈이 아니라
**정문이 가짜였다는 것**이었습니다.

인트로 첫 화면의 유일한 주요 동작 `첫 사건 진입`은 게임을 시작하지 않았습니다.
`showCaseAccessSetup()`은 `scrollIntoView`와 `focus`만 했고, 진짜 시작 버튼
`첫 케이스 시작`은 접힘 아래 설정 폼 안에 있었습니다. 그리고 그 동작은
`tests/season-flow.spec.js`의 `hero entry guides to setup without starting a fresh run`이
**"이 버튼은 판을 시작하지 않는다"고 단언하며 초록불로 고정**하고 있었습니다.
그래서 최근 세 사이클(`4cc147a` → `de06960` → `145352f`)이 문을 열지 못하고
그 버튼의 문구·강조·스크롤만 다듬었습니다. 정체는 취향의 문제가 아니라 계약의 문제였습니다.

### 바뀐 것

- **첫 클릭이 첫 장면을 연다.** 히어로의 주요 동작이 곧 `startNewRun`입니다. 이름을 적지 않아도
  기본값 `분석관`으로 시작하고, 설정 콘솔은 여전히 그 자리에 펼쳐져 있습니다.
- **저장본이 있으면 히어로가 이어하기가 된다.** `.resume-panel`이 첫 화면으로 올라옵니다.
- **인트로가 8화면에서 3.6화면으로 줄었다.** 산문 7개 구획이 닫힌 `<details>`가 되고,
  키 비주얼은 `min(38vh, 340px)`로 잘립니다. 390×844 기준 6,687px → 3,041px.
- **데스크톱에서도 접힘 위에 있다.** 1366×768에서 시작 버튼의 아랫변이 1,116px였습니다.
  화면 밖 348px입니다. 워드마크 상한을 132px→96px로 내리고 제작 크레딧을 비주얼 아래로
  옮겨 625px가 됐습니다.

### 함께 고친 것

콜드 오픈이 스스로의 약속을 지키려면 먼저 고쳐야 했던 두 가지입니다.

- **이어하기가 두 번 눌러야 했습니다.** 셸의 `resumeSavedGame()`이 `runtimeActive`만 세우고
  `started: true`를 저장하지 않아 런타임이 인트로를 다시 그렸습니다. 커밋된 이어하기 테스트가
  모두 `?debug=1`로 들어가는 바람에 이 경로 자체가 한 번도 검사되지 않았습니다.
- **한 번도 플레이하지 않은 사람에게 이어하기가 떴습니다.** 동의 체크나 플레이 성향 선택만으로도
  저장본이 생기는데, 셸의 `hasResumableSave`가 `currentCase && nodeId`만 봤습니다.
  런타임과 같은 정의(`paused`이거나 `log`/`completedCases`가 있을 것)로 좁혔습니다.
- **느린 기기에서 콜드 오픈이 무음으로 열렸습니다.** `playOpeningAccent()`는 공유
  `AudioContext`가 없으면 그냥 빠져나오는데, 그 컨텍스트는 `AdaptiveMusic` 마운트가 만듭니다.
  CPU 10x 스로틀링에서 버튼은 컨텍스트보다 2.7초 먼저 눌립니다. 이제 사용자 제스처 안에서
  없으면 만듭니다. 음소거 확인은 그대로 맨 앞이라 음소거한 사람은 컨텍스트를 하나도 열지 않습니다.

### 게이트

교체한 계약 테스트는 이전보다 강합니다. 이전 테스트는 **빈 스토리지에서 돌아** 스스로 대변하던
세이브 보호를 실제로 증명하지 못했습니다. 새 테스트 쌍은 (1) 한 번의 클릭으로 선택지에 닿는 것과
`opening-burst`가 뜨는 것을, (2) 진짜 중간 저장본을 심고 히어로가 이어하기가 되며
`runId`/`nodeId`/`log`/`completedCases`가 그대로 남는 것을 확인합니다. 여기에 동의 체크가
가짜 이어하기를 만들지 않는다는 회귀 테스트를 더했습니다.

그리고 이번 사이클이 세운 래칫 자체가 실행되지 않고 있었습니다. `visual-regression.spec.js`의
치수 측정 테스트들은 `@visual`이 아니어서 `npm run test:visual`이 건너뛰고, 기본 e2e 목록에는
파일이 없어 **어떤 스크립트도 돌리지 않았습니다**. 인트로가 다시 읽기 예산을 넘겨도 모든 게이트가
초록이었을 것입니다. 기본 실행에 파일을 넣고 `--grep-invert @visual`로 래스터 비교만
전용 워크플로에 남겼습니다. 122개 → 142개.
