# 임계점

인터랙티브 의사결정 게임 **임계점 - 판단이 깊어지는 순간**의 Vite/React 웹 앱입니다.

## 실행

```bash
npm install
npm run dev -- --port 5173
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다.

## 주요 기능

- CASE 01부터 FINAL까지 이어지는 시즌형 의사결정 플로우
- 선택지 전술 등급, 플로우 서지 보너스, 구조 재설계 자유입력, 에코 반론, 자원 변화, 결과 리포트
- 장면별 45초 선택 윈도우와 챌린지 적중 시 빠른 판단 보너스
- 위험 압력 60 이상에서 케이스당 한 번 사용할 수 있는 위기 프로토콜
- 장면과 선택에 집중하는 기본 화면, 필요할 때 여는 자료·에코·상황판 정보 서랍
- 전술 정보를 닫고 직관으로 선택하면 챌린지 적중 시 `INSTINCT SURGE` 보너스
- 결정 윈도우가 끝나도 장면은 계속되며, 시간·피로 비용이 한 번 적용되어 로그에 남음
- 에코에게 장면당 한 번 방향성 힌트를 요청하는 `ECHO PROBE`
- 시작 시 감각형·감사형·중재형 분석 프로토콜을 골라 다른 보너스로 플레이
- 케이스 랭크가 다음 사건의 시작 자원과 서사에 이어지는 `사건 잔향`
- 장면을 생각·지문·대사로 이어지는 소설식 서술로 연출하고, 선택지의 실제 대사를 가장 크게 표시
- Web Audio 기반 무료 배경음악 자동 시작 시도, 자동재생 차단 시 `소리 시작` 재개 버튼, 전역 켜기/끄기 토글
- 브라우저 `localStorage` 기반 진행 저장, 저장 후 나가기, 이어하기
- 플레이 로그 JSON 내보내기
- 선택적 Supabase 원격 저장과 실패분 재시도 대기열

## 파일 구조

```text
index.html             Vite 앱 엔트리와 메타 태그
public/                앱 이미지와 아이콘 자산
src/main.jsx           화면, 상태 관리, 음악 토글, 저장/이어하기, 케이스 전환, 사건 잔향, 분석 프로토콜, 소설식 장면·대사 UI, 선택 타이머, 에코 힌트, 직관 모드, 접힘 정보 서랍, 전술 등급/보너스 UI
src/gameData.js        시즌/케이스/노드/선택지 데이터
src/gameLogic.js       자원 계산, 자유입력 평가, 결과 요약
src/styles.css         UI 스타일
src/telemetry.js       선택적 Supabase 저장 클라이언트
scripts/smoke-test.mjs 핵심 로직 스모크 테스트
render.yaml            Render 정적 사이트 배포 설정
```

## 테스트와 빌드

```bash
npm test
npm run build
```

`npm test`는 자원 변화, 위험 압력, 모멘텀/랭크 계산, 개인정보 감지/익명화, 텍스트 제한 로직을 확인합니다. 선택 타이머는 장면을 강제로 종료하지 않지만, 0초가 되면 시간·피로 비용이 한 번 적용됩니다. 에코 힌트는 장면당 한 번 사용할 수 있으며 기본적으로 결정 시간 8초와 피로 1을 소모합니다. 중재형은 힌트 비용이 결정 시간 4초와 신뢰 1로 바뀝니다. 12초 안에 챌린지를 맞히면 `QUICK READ` 보너스가 적용되고, 감각형이 전술 정보를 닫은 채 챌린지를 맞히면 `INSTINCT SURGE`, 감사형이 전술 정보를 확인한 뒤 챌린지를 맞히면 `AUDIT SURGE`가 적용됩니다. 이전 케이스의 S/A 랭크는 다음 케이스의 신뢰·정당성을 올리고, B/C 랭크는 피로·정당성 비용을 남기며 첫 장면의 챌린지도 바꿉니다. 위험 압력이 60 이상이면 시간·현금을 추가로 소모해 정당성을 회복하는 `위기 프로토콜`을 케이스당 한 번 사용할 수 있습니다.

## 배포

Render 정적 사이트 기준 설정은 `render.yaml`에 들어 있습니다.

- Build Command: `npm ci && npm test && npm run build`
- Publish Directory: `dist`
- Auto Deploy: enabled

선택적 원격 저장을 사용하려면 배포 환경에 아래 값을 설정합니다.

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

두 환경변수가 없으면 앱은 원격 저장을 건너뛰고 로컬 저장과 JSON 내보내기만 사용합니다.
