# 임계점

선택 하나가 다음 사건을 바꾸는 스토리 게임입니다. 어려운 정답을 찾는 게임이 아니라, 시간이 부족하고 사람마다 원하는 것이 다를 때 무엇을 먼저 지킬지 결정하는 게임입니다.

## 실행

```bash
npm install
npm run dev -- --port 5173
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 화면의 `소리 시작` 버튼을 누르면 장면에 맞는 긴장 음악이 재생됩니다.

## 플레이 방법

- 사건을 읽고, 지금 가장 먼저 지킬 것을 고릅니다.
- 선택 전에는 `선택 미리보기`에서 위험과 비용을 확인할 수 있습니다.
- 선택 뒤에는 시간, 현금, 믿음, 공정함, 사람 피해, 지침이 바뀝니다.
- `판 바꾸기`에서는 직접 다른 해결 방법을 적을 수 있습니다.
- 위험을 감수하면서도 장면 목표를 맞히면 사건별 `숨은 단서`를 발견할 수 있습니다.
- 발견한 단서는 보관함에 쌓이고, 마지막 결과에서 실험의 진실을 얼마나 찾았는지 보여줍니다.
- 선택을 확정하면 위험도에 따라 충격 전환, 경고 신호, 단서 발견 연출이 펼쳐집니다.
- 각 사건의 마지막 결정 뒤에 후폭풍 대화가 이어지며, 3가지 대응 방향으로 결과가 갈립니다.
- 사건 중간에도 증언·기록 추적·협상·공개 대응 장면이 이어져, 시즌 전체가 짧은 선택 모음이 아니라 하나의 연속 사건처럼 진행됩니다.
- 연결 장면 뒤에는 인물의 즉시 반응을 다시 선택하는 장면이 이어져, 한 번의 결정을 두 번의 파장으로 경험합니다.
- 마지막 사건은 봉인·개혁·폭로를 중심으로 여러 결말을 만들고, 최종 후폭풍 선택과 단서 수가 결과 문구를 바꿉니다.
- 앞 사건의 선택은 다음 사건의 상황과 결말에 영향을 줍니다.
- 모든 사건을 끝내면 결과, 선택 습관, 참가자 순위를 확인할 수 있습니다.

## 검증

```bash
npm test
npm run build
```

## 주요 파일

```text
src/main.jsx           화면, 저장, 선택 흐름
src/gameData.js        사건, 후폭풍 대화, 선택지, 결말 분기
src/gameLogic.js       점수, 위험, 단서, 결과 계산
src/playerLanguage.js   화면에 보이는 쉬운 표현
src/styles.css         화면 스타일
public/                프로필 및 장면 이미지
scripts/smoke-test.mjs 핵심 계산 테스트
render.yaml            Render 배포 설정
```

## 배포

Render에서 `render.yaml`을 사용합니다.

- Build: `npm ci && npm test && npm run build`
- Publish: `dist`

원격 순위 저장을 연결하지 않아도 플레이할 수 있습니다. 연결하지 않은 경우 기록은 현재 브라우저에 저장되고 JSON으로 내려받을 수 있습니다.
