# 임계점

선택 하나가 다음 사건을 바꾸는 대화형 스토리 게임입니다. 플레이어는 제한된 시간과 자원 안에서 무엇을 먼저 지킬지 결정하고, 그 선택이 다음 사건의 조건과 결말에 반영되는 흐름을 경험합니다.

## 실행

```bash
npm install
npm run dev -- --port 5173
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 화면의 `소리 시작` 버튼을 누르면 장면에 맞는 긴장 음악이 재생됩니다.

일반 브라우저에서는 플레이 진행과 일시정지 상태가 자동 저장되며, 결과 화면에서 플레이 기록을 JSON으로 내려받을 수 있습니다.

## 플레이 방법

- 사건을 읽고, 지금 가장 먼저 지킬 것을 고릅니다.
- 선택 전에는 `선택 미리보기`에서 위험, 보상, 비용을 확인할 수 있습니다.
- 선택 뒤에는 시간, 현금, 믿음, 공정함, 사람 피해, 지침이 바뀝니다.
- 기본 선택지 대신 `판 바꾸기`에서 직접 해결안을 적을 수 있습니다.
- 장면 목표를 맞히면 숨은 단서를 발견하고, 단서 수는 최종 결과에 반영됩니다.
- 사건별 후폭풍 선택은 다음 사건의 시작 상황, 자원 비용, 목표를 바꿉니다.
- 모든 사건을 끝내면 결말, 선택 습관, 참가자 순위를 확인할 수 있습니다.

## 검증

```bash
npm test
npm run build
```

## 주요 파일

```text
src/main.jsx            화면, 저장, 선택 흐름
src/gameData.js         사건, 선택지, 결말 분기
src/gameLogic.js        점수, 위험, 단서, 결과 계산
src/playerLanguage.js   화면 문구 정리
src/styles.css          화면 스타일
public/                 프로필 및 장면 이미지
scripts/smoke-test.mjs  핵심 계산 테스트
render.yaml             Render 배포 설정
```

## 배포

Render에서 `render.yaml`을 사용합니다.

- Build: `npm ci && npm test && npm run build`
- Publish: `dist`

원격 순위 저장을 연결하지 않아도 플레이할 수 있습니다. 연결하지 않은 경우 기록은 현재 브라우저에 저장되고 JSON으로 내려받을 수 있습니다.
